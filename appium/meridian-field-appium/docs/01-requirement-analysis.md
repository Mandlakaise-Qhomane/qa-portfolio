# Requirements

**SUT:** Meridian Field — mobile job app for depot agents.

| ID | Requirement |
|---|---|
| BR-01 | App launch presents a branded sign-in screen |
| BR-02 | Only agent.jhb / Field@123 reaches home |
| BR-03 | Invalid or blank credentials are rejected |
| BR-04 | Logout returns to sign-in |
| BR-05 | Agent can list three open jobs |
| BR-06 | Job 1001 opens as ASSIGNED |
| BR-07 | Start moves the job to IN_PROGRESS |
| BR-08 | Complete after start moves it to COMPLETED |
| BR-09 | A site note is stored on the job |
| BR-10 | Search by text returns job 1001 |
| BR-11 | Priority queue shows only HIGH jobs |
| BR-12 | Offline queue shows a pending-sync banner |
| BR-13 | Settings can change the depot chip |
| BR-14 | Idle timeout expires the session |
