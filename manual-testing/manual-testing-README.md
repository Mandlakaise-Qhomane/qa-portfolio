The 10 test cases cover the most critical workflows in a Health Management / EMR system:

- Patient Registration & Search

- Appointment Scheduling
- Recording Vitals & Biometrics
- Clinical Notes / Encounters
- Patient Check-in / Service Queues
- Session Security after Logout
