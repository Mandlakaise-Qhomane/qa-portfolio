# DEF-001 — VAT calculated before discount

| Field | Value |
| --- | --- |
| ID | DEF-001 |
| Title | VAT used the pre-discount net, so gross was too high |
| Status | **Closed** |
| Severity | Critical |
| Priority | P1 |
| Type | Functional / calculation |
| REQ | REQ-07, REQ-08 |
| Found | 2026-09-11 |
| Closed | 2026-09-12 |

## Steps
1. Qty 2, unit price 50 → net 100.
2. Discount 10% → expected discounted net 90.
3. Observe VAT and gross.

## Expected
VAT = 15% of **90** = 13.50. Gross = 103.50.

## Actual (v0.9)
VAT = 15% of 100 = 15.00. Gross = 105.00.

## Impact
Customers overcharged on every discounted invoice.

## Fix
`VatOn` and `InvoiceGross` use the discounted net. Locked by TC-31 and TC-32.

## Retest
PASS. New → Open → Fixed → Retest → Closed.
