# DEF-004 — Suite cannot run on Linux or macOS hosts

| Field | Value |
| --- | --- |
| ID | DEF-004 |
| Title | `cscript` is not available outside Windows |
| Status | **Closed — environment constraint** |
| Severity | Minor for product; High for CI design |
| Priority | P3 |
| Type | Environment |
| REQ | REQ-01 |

## Description
VBScript executes on Windows Script Host. Ubuntu and macOS runners fail immediately.

## Decision
Not a product defect. CI is pinned to `windows-latest`. Local instructions require Windows. Recorded so reviewers see the constraint was considered.

## Workaround
Run on Windows 10/11 or GitHub Actions windows-latest.
